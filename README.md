# Day 7 Task - Basic Calculator

## 📌 Project Overview

This project is a Basic Calculator developed using HTML, CSS, and JavaScript as part of the Veda Technology Internship - Day 7 Task.

The calculator performs basic arithmetic operations with a simple and responsive user interface.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number calculation
- Clear button
- Equal button
- Divide by zero error handling
- Responsive calculator interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
